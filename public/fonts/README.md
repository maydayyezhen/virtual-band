# ENCORE menu fonts

- **Oxanium**, Severin Meyer / The Oxanium Project Authors. Variable font, weight 200–800. Original binary from https://github.com/google/fonts/tree/main/ofl/oxanium (`Oxanium[wght].ttf`). License: `Oxanium-OFL.txt` (SIL OFL 1.1).
- **Noto Sans SC**, Adobe / Google Fonts. Menu glyph subsets supplied by the Google Fonts CSS API at weights 500, 700 and 900; local filenames and CSS alias are `EncoreMenuSC-*` / `Encore Menu SC`. License: `NotoSansSC-OFL.txt` (SIL OFL 1.1). Source: https://github.com/google/fonts/tree/main/ofl/notosanssc.

The Chinese subset contains the current menu labels and loading/error vocabulary. New text outside this set falls back to the installed Chinese font. Fonts are served locally; the running game does not contact a font CDN.
