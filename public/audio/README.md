# ENCORE game audio

- `menu-loop.mp3`: **The Rift (loop)** by **Vitalezzz**, electronic music with electric guitar. Original MP3 from https://opengameart.org/content/the-rift (CC0). Source file: https://opengameart.org/sites/default/files/the_rift_loop_0.mp3 .
- `hover.ogg`, `confirm.ogg`, `back.ogg`: **Interface Sounds** by **Kenney**, https://kenney.nl/assets/interface-sounds (CC0). Original filenames: `click_001.ogg`, `confirmation_001.ogg`, `back_001.ogg`; license included as `Kenney-License.txt`.

All files are served locally. Menu music is separate from the MIDI transport; a song preview or performance takes over the music output. Interface sounds have a separate quiet bus and do not alter instrument gain settings.
