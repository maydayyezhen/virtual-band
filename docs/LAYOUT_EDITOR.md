# 乐器摆放编辑器

摆放编辑器是独立开发工具，不会启动成品页的演奏、音频或乐器交互逻辑。

## 启动

```powershell
npm run dev
```

打开 `http://127.0.0.1:5173/layout.html`。

## 操作

- 点击乐器卡片或三维模型进行选择。
- 在模型上拖动，修改地面平面中的 X / Z 位置。
- 按住 `Shift` 横向拖动模型，只改变水平朝向。
- 在空白处拖动旋转镜头，滚轮缩放。
- 使用面板调整水平朝向、锁定乐器、撤销或重做。
- “复制当前”和“删除当前”用于调整乐器实例数量，同一种乐器可以出现多次。
- “自动排位”根据每个实例的真实占地分配前后排：鼓和键盘进入后排，其他乐器进入前排；空间不足时自动增加一排。
- 六件模型载入后会先测量自身包围盒，并归一化到现实参考总高；场景单位统一为米，`1×` 代表该乐器的现实基准大小。
- 使用“比例（现实基准）”继续等比微调，范围为 `0.1–5`；缩放时会自动调整 Y，使模型底部保持在原来的地面高度。
- `Y` 高度由贴地逻辑自动维护，只读显示。
- “保存 JSON”导出布局，“加载 JSON”读取并校验布局。

## JSON 边界

布局文件只包含版本号、场地标识、布局名称，以及乐器实例数组。每个实例有独立 ID、乐器类型、位置、旋转和比例，因此可以保存多个同类乐器。它不包含模型、音频配置或运行时状态。当前成品页不会自动读取这些文件；确认布局后再单独接入，可以避免编辑工具影响现有演奏逻辑。

运行格式校验：

```powershell
npm run layout:verify
```
